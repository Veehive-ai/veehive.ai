Using it

One line, then never a raw value

Link the stylesheet once and every token is available. The rule that makes it worth doing: no hex codes, pixel sizes or durations written by hand in a product. If a value is missing, add a token rather than an exception.

<link rel="stylesheet" href="https://veehive.ai/brand/tokens.css">

Do

  • color: var(--vh-color-text)
  • padding: var(--vh-space-4)
  • Let the theme flip the value; never branch on it yourself.
  • Add a token when one is missing, and say what it is for.

Don't

  • color: #FFFFFF — it will be wrong in one theme.
  • A product colour to mean a state, or a state colour to brand.
  • Removing the focus outline. Replace it with something louder or leave it.
  • New radii, durations or spacing steps invented per screen.
