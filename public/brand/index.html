The mark

Six petals, six apps

Each petal carries one product colour, in a fixed arrangement. The mark can stand alone wherever the name is already present — app icons, avatars, favicons.

Clear space. Keep free space on all sides equal to the height of one petal. Nothing sits inside it.

Minimum size. 24 px for the mark, 120 px wide for the full logotype. Below that the petal gaps close up.

Motion

The mark in motion

The mark is radially symmetric, so it rotates about its own centre without ever looking tilted — which makes it the loading state everywhere. Six timings, pure CSS, no JavaScript. Use the default unless there is a reason not to.

Fast.veehive-loader-fast0.6s linear

Flip.veehive-loader-flip1.5s rotateY

Spin the padded mark, not the plain one — the padding keeps the petals from clipping at the corners of the box. Every product mark is padded the same way, so a product’s own colour can carry its loading state. The full demo, with all six side by side on light and dark, is in brand/loaders/.

Product logotypes

One lockup per product

Each product sets its own name beside the mark in its own colour, on the same geometry as Veehive.ai — Manrope ExtraBold, cap height 80.64 on a 105.32 baseline, the mark at 0.9 and the same gap to the first letter. The name is never set in another weight, and never in the product colour: the mark carries the colour, the name stays in the neutral.

Merch

On cloth

Three placements. The full logotype sits centred on the chest, and small — it is a shirt, not a billboard. The mark alone sits at the left chest (the wearer’s left, so the right as you look at it), about a hand’s width down from the shoulder seam. And the mascot sits above the wordmark where the piece is meant to be fun rather than corporate. Print the white logotype on anything darker than the mid-grey, the dark one on anything lighter — never a drop shadow, never an outline to make it work on a difficult colour.

Email signature

One signature, every inbox

Tables and inline styles, because that is still what mail clients want. The logo loads from veehive.ai so it survives the trip into someone else’s inbox — never paste a screenshot of it, and never attach it. The pink rule is HiveFront’s, the one accent the signature carries.

Using it

Rules that matter

✓Do

  • Use the supplied SVG wherever it will scale.
  • Pick the version that matches the ground: dark wordmark on light, white on dark.
  • Keep one petal-height of clear space around the mark.
  • Let the mark stand alone when the name is already on the page.

×Don't

  • Recolour, rotate or redraw the petals, or change their arrangement.
  • Move the pink dot, or add pink anywhere else in the logotype.
  • Stretch, shear or outline the logotype, or add a shadow to it.
  • Set the wordmark in another typeface, or retype it instead of using the file.
  • Place the full-colour mark on a busy photograph without a clear plate behind it.
