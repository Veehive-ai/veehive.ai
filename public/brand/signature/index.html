Putting it in

  1. Gmail: Settings → See all settings → Signature. Paste with Cmd/Ctrl + V.
  2. Outlook (web): Settings → Mail → Compose and reply → Email signature.
  3. Outlook (desktop): File → Options → Mail → Signatures.
  4. Apple Mail: Settings → Signatures, then untick “Always match my default message font”.

If a client strips the formatting, use Copy the HTML and paste into whatever “edit source” or “HTML” field it offers.
